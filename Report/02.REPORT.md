## 4. 아키텍처 결정 (Rationale)

### 4.1 ECB 단방향

```
boundary → control → entity
```

- **entity:** 순수 Rule — E001~E005 **비침범**
- **control:** entity 조율, boundary 오류 **전달**
- **boundary:** E001~E007, I/O·사용자 메시지

### 4.2 Dual-Track TDD

| 이유 | 내용 |
|------|------|
| Logic Mock 금지 | 판정 계약(INV)이 **실 Rule** 과 일치해야 SC-3(회귀) 성립 |
| UI Mock 허용 | boundary는 **입력 검증·표시** — control stub으로 D-* 와 분리 |

### 4.3 MagicConstant SSOT

Mom Test **SC-2**(10선·빈칸 2·중복 누락 금지)와 연결 — `34`/`16` 이 테스트·구현에 흩어지면 **기준 drift** 위험.
