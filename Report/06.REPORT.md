## 3. 상위 5 스멜 ↔ 리팩터링 기법

| 순위 | 스멜 | 적용 기법 | 이 레포에서 하는 일 |
|:---:|------|-----------|-------------------|
| **1** | 10선·34 중복 예고 | **Extract Module** · **Pull Up Method** | `entity/line_rules.py`(가칭): `ten_lines()`, `all_lines_sum_to(grid, MAGIC_SUM)` — `solve_step_a`·향후 `validate_board` 공용 |
| **2** | ECB 미완성 | **Move Method** · **Introduce Facade** | `validate_board` → **control**; E001~E007 → **boundary**; entity는 Rule만 |
| **3** | Primitive Obsession | **Introduce Value Object** · **Replace Primitive with Object** | `Grid` VO — 생성 시 4×4·빈칸 2·중복 검사 |
| **4** | Golden 이중 SSoT | **Single Source of Truth** · **Load Fixture from File** | `d_loc_01_g1.json` 단일 소스 → conftest·approved 파생 |
| **5** | int[6] Data Clump | **Introduce Parameter Object** · **Move Function** | `StepAResult` + `to_int6()` / `to_golden_text()` — `_coords_to_int6`·serializer 통합 |

### 3.1 보조 기법

| 기법 | 울 시 |
|------|--------|
| **Rename Method** | VO·Rule API 이름을 PRD int[6]·1-index 계약에 맞출 때 |
| **Preserve Whole Object** | `Grid`·`StepAResult`를 필드 단위로 흩뿌리지 않을 때 |
| **Inline Method** | Rule 추출 후 1줄 래퍼만 남을 때 |
